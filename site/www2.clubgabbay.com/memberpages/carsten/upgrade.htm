The CPU - upgrade value = 100 %

The Central Processing Unit is the most important part on a computer.
The clock rate of the CPU determines the speed of the whole computer,
so it´s important to have a fast CPU.
Tip: Try to move to the next generation of CPU´s on upgrading the system.
For example, if you have a 486-133 MHz, you should upgrade to a Pentium 133 MHz.
Otherwise, if you have a slow 486 (e.g. 33 MHz) and your mainboard allows faster CPUs
you could try to upgrade to a 486 running at 133 MHz. Upgrades in one generation are only a good
solution in this second case mentioned or if there´s not enough money !
Current best buy is the Pentium 133 MHz, but now coming up the Pentium 166 MHz.
Remember you need a board that supports the processor !


The MainBoard - upgrade value = 50 %

What´s a new processor without a mainboard offering possibility to run all
the processor´s features ? If you plan to buy a new board be sure to check
if it´s upgradable. E.g. Pentium Boards should be able to run Pentiums
at 200 MHz, latest revisions should be able to run 300 MHz Pentiums.
Make sure the board has got Pipeline-Burst-Cache (Standard today) and
allows to put up to 128 MB of EDO-RAM onto it using PS-2/SIMM or DIMM modules. DIMMS are the latest development.
If you plan to go upgrade to a higher processor than a Pentium you should also watch to get the latest
release on the board, also featuring the latest PnP-BIOS !!!


The RAM - upgrade value = 100 %

Your computer needs RAM like you need food to live.
The more RAM you have the better and faster your programs will run.
Especially if you use Win95 you should have minimum 16 MB, better 32 MB of RAM
in your machine. Important on RAM is that you buy chips with a fast access time,
that should be faster or equal to 60 ns. Also there are modules with Parity and others
without Parity. For a standard PC those non-parity modules are enough.
Tip: DOS / Windows 3.11 can use a maximum of 64 MB of RAM. So it won´t make sense
to put more in it. If you use Win95 you can put up to 128 MB of RAM in it.
Prices for RAM change from day to day, so keep watching them before you buy !!!


The Harddisk - upgrade value = 75 %

RAM isn´t all you need for your programs. A fast harddisk is important too.
There are two different types of harddisks. One type is the IDE-harddisk,
the other type is the SCSI-harddisk. The type you have to use depends on the
Controller you use for your harddisks.
Standard are IDE-drives, and they´re also cheaper than SCSI-drives.
If you plan to buy a new drive, look for the following charateristic things on a drive:
1) RPM: The higher the better, standard is 5400 rpm, SCSI should have 7200 rpm
2) Transferrate: Depending on the RPM, the higher the better.
3) Access time: Should be under 10 ms, good drives offer 6 or 7 ms.


The Controller - upgrade value = 75 %

Modern boards have controllers onboard, so there´s no upgrade possible.
But if you have a separate controller in your system you should check if it
is only an ISA-bus based one, or a PCI or VLB-bus controller.
If you want to buy a SCSI-harddrive you have to get a SCSI-Controller too.
SCSI is a bit more expensive, but also more flexible and faster.
Best SCSI-Controllers are made by ADAPTEC.
For IDE-Controllers watch out that they support up to FOUR drives.
