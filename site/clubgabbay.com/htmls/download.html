Down Load Utility

Using this utility will allow you to speed up your chatting experience dramatically. Clicking on Begin below will take you to our DownLoad page where all the images for the ClubGabbay site will start to download into you cache. To take advantage of this feature, you must first set a few things on your browser. Depending on the brand of your browser, the settings may be titled differently. First check to see that your disk cache is set to 'Check documents Never' and the disk cache size is at least Mb. Once this is checked, click on begin below.

Note: This is not a Java applet and no source code will be downloaded to your computer. This is simply a pre-load of images that will be used within the ClubGabbay site. If you have any questions about this utility, please send an e-mail to help@ClubGabbay.com.
