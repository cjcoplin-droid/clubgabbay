Here we give you the chance to take a look at things that are
currently under development or just cam on the market.

Intel, world´s most famous processor giant, just put the new MMX-CPUs on the market.
MMX means the processor got an eXtension on MultiMedia commands.
By this Intel wants to achieve that AVI and MPEG runs faster on PC-systems, the only problem
about it is that you need a special software that can run these commands. This software is
currently under development.
As another step Intel decided to put more L1-Cache into the processor, now including 32 kB.
Our testing center had the great honour to test this MMX-Pentium at 166 MHz (delivery only with 166 or
200 MHz) and we compared it to a standard P166 and a standard P200. Well, we didn´t feel much difference while working on the machine, so we decided to use a benchmark
program. The results were like we expected: The new MMX-166 was about 5 percent faster than his standard 166 MHz-brother.
But the 200 MHz standard chip was still alot faster than this MMX-Pentium. Other test results that Intel
provided said the MMX-166 would be faster than the 200 MHz standard processor. But Intel was wrong.
Maybe the MMX will speed up a little more with optimated software, but we couldn´t test that yet.
About the prices:
The MMX is a little bit more expensive than the standard chip, but soon prices should fall.
So if you can get a cheap MMX you should buy it, especially the 166 MHz version.
The 200 MHz is still too expensive.

Microsoft is currently working on another upgrade for Windows 95 and Windows NT 4.0.
Both service packs should be provided in summer, including new bugfixes and improved kernels.
Windows 95 features for multitasking shall be improved even more so that Windows 95 moves closer
to Windows NT.
