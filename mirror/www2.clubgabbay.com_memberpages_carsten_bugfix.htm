Microsoft found a bug in Windows 95.
If your PCI-System sometimes hangs and you´re running Windows 95 or DOS 6.22 you should take
a close look at the date of the file EMM386.EXE. If the file is older than 06.06.94 then you should try to
get a newer release. Later versions of Windows 95 were provided with this driver.
